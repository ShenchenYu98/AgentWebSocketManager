# Agent WebSocket 前端 SDK 需求文档

## 1. 项目背景

在 Agent 对话系统中，前端页面需要与 Agent 服务端进行实时通信，包括：

-   用户消息发送
-   Agent 流式响应接收
-   tool / skill 调用事件回传
-   会话状态同步
-   心跳与断线重连
-   多会话管理

为避免每个业务前端重复实现复杂的 WebSocket 会话控制逻辑，设计一个
**独立的前端 SDK**：

> SDK
> 对外仅提供统一通信方法，会话生命周期、网络管理、消息调度、重连机制等全部由
> SDK 内部托管。

------------------------------------------------------------------------

## 2. 设计目标

### 2.1 功能目标

-   管理 WebSocket 长连接
-   管理用户与 Agent 的会话 session
-   支持流式响应
-   支持请求-响应映射（requestId）
-   支持断线自动重连
-   支持心跳检测
-   支持多会话隔离
-   支持事件订阅机制
-   支持 token 过期自动刷新

### 2.2 非功能目标

-   轻量级（\< 30KB gzipped）
-   TypeScript 强类型支持
-   不依赖具体框架（Vue / React / 小程序）
-   可运行于浏览器、Electron、小程序（通过适配层）

------------------------------------------------------------------------

## 4. 核心模块设计

### 4.1 WSManager（连接管理）

职责：

-   创建 WebSocket 连接
-   维护连接状态
-   统一发送与接收消息
-   触发连接事件

连接配置：

``` ts
interface WSOptions {
  url: string
  token?: string
  protocols?: string[]
  reconnect?: boolean
  maxReconnectAttempts?: number
  reconnectInterval?: number
}
```

连接状态：

    INIT → CONNECTING → OPEN → CLOSED → RECONNECTING

------------------------------------------------------------------------

### 4.2 SessionManager（会话管理）

职责：

-   管理 sessionId
-   支持多会话
-   切换会话
-   会话缓存

``` ts
interface Session {
  sessionId: string
  userId: string
  status: 'active' | 'closed'
  metadata?: Record<string, any>
}
```

提供方法：

-   createSession()
-   getSession()
-   switchSession()
-   closeSession()

------------------------------------------------------------------------

### 4.3 MessageDispatcher（消息调度）

实现 request-response 映射机制。

流程：

    send(message)
      → 生成 requestId
      → 存入 pendingMap
      → 等待 response

数据结构：

``` ts
interface PendingRequest {
  resolve: Function
  reject: Function
  timeoutId: number
}

Map<requestId, PendingRequest>
```

------------------------------------------------------------------------

### 4.4 EventBus（事件系统）

用于向业务侧暴露 SDK 事件。

API：

    on(event, handler)
    off(event)
    emit(event)

事件列表：

  事件             说明
  ---------------- ----------
  open             连接建立
  close            连接关闭
  error            网络错误
  message          收到消息
  stream           流式数据
  sessionChanged   会话切换

------------------------------------------------------------------------

### 4.5 HeartbeatManager（心跳机制）

目的：

-   检测连接是否存活
-   防止中间代理断开连接

机制：

-   每 20 秒发送 ping
-   服务端返回 pong
-   若超时未响应则触发重连

------------------------------------------------------------------------

### 4.6 ReconnectManager（断线重连）

重连策略：

指数退避算法

    1s → 2s → 4s → 8s → 16s

配置：

-   最大重连次数
-   最大间隔时间
-   是否自动重连

------------------------------------------------------------------------

## 5. SDK 对外 API 设计

### 初始化

``` ts
const sdk = new AgentSDK({
  url: "wss://agent-server.com/ws",
  token: "xxx"
})
```

------------------------------------------------------------------------

### 核心通信方法

``` ts
sdk.send({
  type: "chat",
  sessionId: "xxx",
  payload: {
    content: "你好"
  }
})
```

返回：

    Promise<Response>

------------------------------------------------------------------------

### 流式监听

``` ts
sdk.on("stream", chunk => {
  console.log(chunk)
})
```

------------------------------------------------------------------------

### 事件监听

``` ts
sdk.on("open", () => {})
sdk.on("close", () => {})
sdk.on("error", err => {})
sdk.on("message", data => {})
```

------------------------------------------------------------------------

### 会话管理

``` ts
sdk.createSession()
sdk.switchSession(sessionId)
sdk.getCurrentSession()
```

------------------------------------------------------------------------

## 6. 消息协议设计

### 请求

``` json
{
  "requestId": "uuid",
  "type": "chat",
  "sessionId": "xxx",
  "payload": {
    "content": "你好"
  }
}
```

### 响应

``` json
{
  "requestId": "uuid",
  "status": "success",
  "data": {},
  "error": null
}
```

### 流式数据

``` json
{
  "requestId": "uuid",
  "type": "stream",
  "chunk": "你好"
}
```

------------------------------------------------------------------------

## 7. 异常处理

  场景             处理方式
  ---------------- -------------------
  WebSocket 断开   自动重连
  请求超时         Promise reject
  Token 过期       触发 refreshToken
  服务端错误       抛出异常

------------------------------------------------------------------------

## 8. 安全机制

-   请求签名（可选）
-   requestId 防重复提交
-   消息序列号校验

------------------------------------------------------------------------

## 9. 生命周期
