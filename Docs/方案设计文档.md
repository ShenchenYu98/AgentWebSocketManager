# Agent WebSocket 前端 SDK

## 架构设计文档 & 技术设计文档

Version: 1.0

------------------------------------------------------------------------

# 1. 文档目标

本文档用于描述 **Agent 前端 WebSocket SDK**
的完整架构设计与技术实现方案， 用于指导 SDK 的开发、评审与后续维护。

该 SDK 主要解决：

-   Agent 前端与服务端通信标准化
-   WebSocket 连接生命周期管理
-   会话（Session）管理
-   请求响应调度
-   流式消息处理
-   弱网与断线恢复

目标：

> 让业务前端仅通过一个 SDK 即可稳定接入 Agent 对话服务。

------------------------------------------------------------------------

# 2. 系统架构

整体架构分为 4 层：

    ┌─────────────────────────────┐
    │        Application          │
    │   Chat UI / Business App    │
    └───────────────▲─────────────┘
                    │
    ┌───────────────┴─────────────┐
    │           SDK API Layer      │
    │   send() / on() / session()  │
    └───────────────▲─────────────┘
                    │
    ┌───────────────┴─────────────┐

    │ Event Bus                    │
    │ Heartbeat Manager            │

                    │
    ┌───────────────┴─────────────┐
    │       Transport Layer        │
    │          WebSocket           │
    └─────────────────────────────┘

# 3. 设计原则

### 3.1 高内聚

网络逻辑全部封装在 SDK 内部。

业务代码无需关心：

-   重连
-   心跳
-   消息队列
-   请求超时

------------------------------------------------------------------------

### 3.2 可扩展

SDK 支持：

-   middleware
-   plugin

------------------------------------------------------------------------

### 3.3 无框架依赖

SDK 不依赖：

-   Vue
-   React
-   Angular

仅依赖 WebSocket API。

# 6. 核心类设计

# 7. ConnectionManager

负责 WebSocket 连接。

状态机：

    INIT
     ↓
    CONNECTING
     ↓
    OPEN
     ↓
    CLOSED
     ↓
    RECONNECTING

核心方法：

    connect()

    disconnect()

    send()

    handleMessage()

------------------------------------------------------------------------

# 8. SessionManager

负责会话管理。

支持：

-   多 session
-   session 切换

```{=html}
<!-- -->
```
    interface Session {

     sessionId: string
     userId: string
     status: string

    }

------------------------------------------------------------------------

# 9. MessageDispatcher

负责请求响应映射。

实现 requestId → Promise。

    Map<requestId, PendingRequest>

发送流程：

    send()
      ↓
    create requestId
      ↓
    store promise
      ↓
    send websocket
      ↓
    resolve on response

------------------------------------------------------------------------

# 10. EventBus

事件系统。

    on(event, handler)

    emit(event)

    off(event)

支持事件：

  Event     Description
  --------- -------------
  open      连接建立
  close     连接关闭
  message   普通消息
  stream    流式消息
  error     错误

------------------------------------------------------------------------

# 11. HeartbeatManager

实现 ping/pong。

    ping interval: 20s
    timeout: 10s

若超时：

    trigger reconnect

------------------------------------------------------------------------

# 12. ReconnectManager

实现自动重连。

算法：

    1s
    2s
    4s
    8s
    16s

最大次数可配置。

------------------------------------------------------------------------

     ↓

     ↓

# 15. 流式消息处理

Agent 返回 streaming 数据。

流程：

    server chunk
     ↓
    websocket message
     ↓
    dispatcher
     ↓
    emit stream event
     ↓
    UI append text
