# AgentSDK Web 测试控制台使用指南

## 1. 环境准备

### 1.1 启动后端服务

需要启动两个服务：

```bash
# 终端1: 启动 WebSocket Mock 服务器 (端口 8082)
cd mock-server
npm run dev

# 终端2: 启动 HTTP 服务器 (端口 8080)
cd 项目根目录
npx http-server -p 8080
```

### 1.2 访问测试页面

打开浏览器访问：
```
http://localhost:8080/mock-server/src/test-console.html
```

---

## 2. 页面功能介绍

### 2.1 连接配置面板

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| WebSocket URL | `ws://localhost:8082` | WebSocket服务器地址 |
| Token | 空 | 可选的认证令牌 |
| 心跳间隔 | 20000ms | 20秒发送一次心跳 |
| 请求超时 | 20000ms | 请求超时时间 |

**操作按钮：**
- **连接**: 建立WebSocket连接
- **断开**: 主动断开连接
- **状态标签**: 显示当前连接状态（未连接/连接中/已连接）

### 2.2 连接状态统计

| 统计项 | 说明 |
|--------|------|
| 已发送 | 发送的消息总数 |
| 已接收 | 接收的消息总数 |
| 流式消息 | 接收的流式数据块数 |
| 会话数 | 当前活跃的会话数量 |
| 重连次数 | 自动重连的次数 |

### 2.3 发送消息面板

**消息类型选择：**
- **chat**: 普通聊天消息
- **stream**: 流式响应消息
- **ping**: 心跳检测
- **createSession**: 创建新会话
- **switchSession**: 切换到指定会话
- **closeSession**: 关闭当前会话

**使用步骤：**
1. 选择消息类型
2. 填写会话ID（可选，不填使用当前会话）
3. 填写消息内容（JSON格式）
4. 点击"发送消息"

**示例消息内容：**
```json
{"content": "Hello, Agent!"}
```

### 2.4 会话管理面板

**功能：**
- **创建会话**: 输入用户ID（可选），点击按钮创建新会话
- **关闭当前会话**: 关闭当前活跃的会话
- **会话列表**: 显示所有会话，可点击切换
- **当前会话**: 显示当前使用的会话ID

### 2.5 流式消息输出

- 显示流式消息的实时输出
- 支持清空操作
- 自动拼接流式数据块

### 2.6 事件日志

**日志类型及颜色：**
- 🔵 **info** (灰色): 一般信息
- 🟢 **open** (绿色): 连接建立
- 🔴 **close** (红色): 连接关闭
- 🟠 **error** (橙色): 错误信息
- 🟡 **message** (黄色): 消息收发
- 🔵 **stream** (青色): 流式数据

## 3. 典型测试场景

### 3.1 基础连接测试

1. 保持默认配置，点击"连接"
2. 观察状态变为"已连接"（绿色）
3. 查看日志显示"连接已建立"
4. 点击"断开"，观察状态变化

### 3.2 发送普通消息

1. 连接成功后
2. 消息类型选择"chat"
3. 内容填写 `{"content": "你好"}`
4. 点击发送
5. 查看响应消息和日志

### 3.3 测试流式响应

1. 连接成功后
2. 消息类型选择"stream"
3. 内容填写 `{"content": "这是一段测试流式消息"}`
4. 点击发送
5. 观察"流式消息输出"面板逐字显示
6. 查看统计中的"流式消息"计数增加

### 3.4 会话管理测试

1. 点击"创建会话"
2. 观察会话列表出现新会话
3. 当前会话显示新会话ID
4. 创建多个会话测试切换功能
5. 测试关闭会话

### 3.5 重连测试

1. 建立连接后，断开Mock服务器
2. 观察日志显示"正在重连..."
3. 重新启动Mock服务器
4. 观察自动重连成功

## 4. 调试技巧

### 4.1 浏览器控制台

打开浏览器开发者工具(F12)查看：
- SDK加载调试信息
- 详细的错误信息
- 网络请求状态

### 4.2 Mock服务器控制台

在Mock服务器终端输入命令控制服务器行为：

```
/delay 500       # 设置响应延迟500ms
/error 0.1       # 设置10%的错误率
/stream async    # 设置流式模式
/stats           # 查看服务器统计
/reset           # 重置所有设置
```

### 4.3 常见问题排查

| 问题 | 排查方法 |
|------|----------|
| 连接失败 | 检查Mock服务器是否启动，端口是否正确 |
| SDK未加载 | 检查控制台是否有脚本加载错误 |
| 消息无响应 | 检查JSON格式是否正确 |
| 会话无法切换 | 确认会话状态不是closed |

## 5. 页面布局说明

页面采用响应式布局：
- **桌面端**: 左右分栏显示（发送消息 | 会话管理）
- **移动端**: 单栏垂直排列

所有面板都可以独立滚动，方便查看大量日志和消息。
